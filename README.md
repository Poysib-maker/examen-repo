# 🛍️ Название вашего интернет-магазина / сайта

> Веб-сайт на ASP.NET Core MVC с механикой товаров, интеграцией корзины и личного кабинета.

---

## ✨ Основные возможности (Features)

*   🔍 **Умный поиск и фильтрация** — мгновенный поиск товаров по ключевым словам.
*   🛒 **Корзина покупок** — добавление, удаление товаров относительно корзины и формирование заказа.
*   👤 **Личный кабинет** — авторизация пользователей, история заказов и управление профилем, а так же управление сайтом с аккаунта администратора.
*   🎨 **Адаптивный дизайн** — сайт полностью оптимизирован под мобильные устройства и планшеты благодаря Bootstrap 5.

## 🛠️ Стек технологий (Tech Stack)

*   **Backend:** C#, .NET 9, ASP.NET Core MVC, Entity Framework Core
*   **Database:** InMemoryDatabase
*   **Frontend:** HTML5, CSS3, JavaScript, Bootstrap 5
*   **Архитектура:** MVC (Model-View-Controller), GodController Pattern

## 🚀 Как запустить проект локально

Выполните эти шаги, чтобы развернуть сайт на своем компьютере.

### 1. Требования (Prerequisites)
У вас должны быть установлены:
*   [.NET SDK](https://microsoft.com) (версии 8.0 или выше)
*   [Visual Studio 2022](https://microsoft.com) или JetBrains Rider / VS Code
*   Необходимые библиотеки (см. логи ошибок при неудачных запусках)

### 2. Клонирование репозитория
```bash
git clone https://github.com
cd examen-repo
```

### 3. Настройка конфигурации (Строка подключения)
Откройте файл `appsettings.json` в корне проекта и обновите строку подключения к вашей базе данных:

```json
"ConnectionStrings": {
  "DefaultConnection": "Server=(localdb)\\mssqllocaldb;Database=YourDbName;Trusted_Connection=True;MultipleActiveResultSets=true"
}
```

### 4. Применение миграций базы данных
Откройте терминал в папке проекта и создайте базу данных:
```bash
dotnet ef database update
```
*(Или выполните команду `Update-Database` в Консоли диспетчера пакетов в Visual Studio).*

### 5. Запуск приложения
```bash
dotnet run
```
После этого сайт станет доступен по адресу: `http://localhost:5131` (или другому порту, указанному в консоли).

## 📁 Структура проекта (необязательно, но полезно)

*   `/Controllers` — логика обработки запросов и редиректов.
*   `/Models` — сущности базы данных и ViewModels.
*   `/Views` — интерфейс страниц (.cshtml файлы, разметка Bootstrap).
*   `/wwwroot` — статические файлы (стили CSS, скрипты JS, изображения товаров).
